**General Notes:**

* Variables indicated as "Applies only to academic staff" or "Applies only to non-academic staff" will have null (NaN) values for respondents in the other group. The count `n` indicates the number of non-null values for that specific group as observed in the initial analysis (applicability based on specific questions should be verified against the questionnaire).
* The "Values/Range" column for categorical variables lists the specific codes and labels extracted or inferred from the questionnaire PDF. Some variables allowed an "Other" option or combinations.
* The storage data type (e.g., `float64`, `int64`) is listed in the Notes. Conceptually categorical variables might be stored as floats due to NaN values or the original coding scheme.
* Null value counts are calculated as Total Observations (2748) minus the Non-null count previously provided.
* Variables like `Performance_Pressure`, `Perceived_Autonomy`, etc., are noted as likely derived from averages of multiple Likert scale questions based on their numeric nature with many unique values. The exact underlying questions for these constructs would be found in the survey sections (e.g., pages 10-20 for Autonomy/Pressure, pages 11-12 for Leadership, pages 12-13 for Community, pages 13-15 for Satisfaction, pages 20-21 for Burnout aspects, as per original notes).
