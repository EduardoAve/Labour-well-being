**General Notes:**

* Variables indicated as "Applies only to academic staff" or "Applies only to non-academic staff" will have null (NaN) values for respondents in the other group. The count `n` indicates the number of non-null values for that specific group.
* The "Values/Range" column for categorical variables lists the specific codes and labels extracted from the questionnaire PDF[cite: 1]. Some variables allowed an "Other:" option.
* The storage data type (e.g., `float64`, `int64`) is listed in the Notes. Conceptually categorical variables might be stored as floats due to NaN values or the original coding scheme.
* Null value counts are calculated as Total Observations (2748) minus the Non-null count previously provided.
* Variables like `Performance_Pressure`, `Perceived_Autonomy`, etc., are noted as likely derived from averages of multiple Likert scale questions based on your initial description and their numeric nature with many unique values. The exact underlying questions for these constructs would be found in the survey sections (e.g., pages 10-20 for Autonomy/Pressure, pages 11-12 for Leadership, pages 12-13 for Community, pages 13-15 for Satisfaction, pages 20-21 for Burnout aspects).
* Unclear Codes: Some variables in the original table had unique value counts higher than the options listed in the PDF (e.g., `Marital_Status` code 6, `HEI_Type` codes 4-8). These discrepancies need further investigation in the raw data or processing script (`Data_preparation.ipynb`) to clarify their meaning. The `Current_Position` variable also needs clarification regarding code 0 and codes 9-13, potentially relating to how non-academic staff or combined roles were coded.
